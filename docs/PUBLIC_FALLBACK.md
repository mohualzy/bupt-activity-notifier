# 零操作优先：公开校园活动线索监控

## 重要：这是补充源，不是完整第二课堂

为了满足“用户不想每隔几天登录一次”的偏好，本分支 `feature/zero-click-public-fallback` 引入一个**独立运行、无需二课 Token** 的官方校园公告抓取程序。

与既有精确监控的区别：

| 性质 | 官方第二课堂监控 | 公开线索备用监控 |
| --- | --- | --- |
| 数据源 | 登录后的二课学生活动接口 | 学生处与后勤部公开通知公告 |
| 需要 Token | 是，3 天左右到期 | **完全不需要** |
| 目标筛选 | 沙河 + 签到 + 无签退 | 公告文本中有沙河/二课/两校区等线索 |
| 覆盖率 | Token 有效时较完整 | **不完整，且更新可能迟缓** |
| 用户日常操作 | Token 过期需要合法续期 | **零操作（电脑开机并已登录）** |
| 微信通知 | 已经实测真实送达 | 复用已经配置的 ServerChan，无需注册新账户 |

公开源：

1. [北京邮电大学学生处：通知公告](https://xsc.bupt.edu.cn/xgdt/tzgg.htm)
2. [北京邮电大学后勤部：通知公告](https://hq.bupt.edu.cn/tzgg.htm)

这两处是正常可匿名访问的 **HTTPS 公告页面**。部分公告确实是沙河校区、学生报名、志愿活动等；但普通二课的活动不一定在公告网站发布，且网站公告列表不保证最新或完整。**2026-10-14 观察到学生处最新公告仍为 2026-07，后勤部最新公告为 2026-10-08。**不可宣称与官方二课 API 等价。

### 运行机制

- 每 30 分钟抓取公开通知列表。只访问两个已明确白名单列出的大学官网，并且只跟随其本站 `/info/{section}/{id}.htm` 文章链接。
- 每个源首次成功访问只建立**已发布文章基线**，不会追发历史公告，也不会额外发一条干扰用户的测试微信。
- 之后只检查新链接。标题需表示报名/活动/讲座/志愿等，正文需出现“沙河”、“第二课堂”、“二课”或“两校区”等线索；发布日期不得超过 21 天。
- **所有推送标题都会标记“公开活动线索（非二课核验）”**，正文注明未知校区、签到、签退、可报名性及漏报风险，并提供原文链接。
- 复用现有本机私有 `.env` 的 ServerChan 或 OneBot 配置；**不读取也不使用原有 `SECONDCLASS_TOKEN`、Cookie、密码或现有 Edge 登录态**。
- 用独立的 `.state/public_seen.json` 去重。每个微信推送成功后立即落盘确认；推送失败会待下次轮询重试。官方源返回 412/404/超时不会抹掉去重状态。
- 使用独立 `BUPT-Public-Activity-Watcher` Windows 登录自启任务和 `logs/public_watch.log`；不重启、不改造原先 `BUPT-SecondClass-Activity-Watcher`。

### 当前机器部署

独立代码目录：`D:\Projects\bupt-activity-notifier-public`。

手动本地只读测试（不会发送任何微信或写入去重）：

```powershell
cd D:\Projects\bupt-activity-notifier-public
python scripts\public_windows_watch.py --dry-run
```

创建 baseline 并执行一次轮询（首次不会发通知）：

```powershell
python scripts\public_windows_watch.py --once
```

后台运行由 Windows 任务计划程序在用户登录后启动，无需打开终端。日志和本地私有状态放在原有稳定项目下的 `logs\public_watch.log`、`.state\public_seen.json`；已被 `.gitignore` 排除。

### 限制与风险

1. **“零操作”不意味着完整活动覆盖**。这套补充抓取不能替代官方二课所有签到/签退字段。官网没发公告就可能完全漏掉。
2. 不是远程全天候服务：**仅电脑开机、网络可用且本机用户已登录时运行**。如果以后要求关机继续监控，需要独立的云部署和消息渠道迁移。
3. 只读公开页面、不爬验证码、不突破身份权限；站点拒绝访问时等待下个周期，不使用隐藏自动化特征。
4. 公告重复转载、晚发或发布时间缺失时，不保证百分百覆盖。宁可不推送也不把过期信息包装成新活动。
5. 现有微信新活动精确提醒已正常实测。二课 JWT 有效期间**两套程序并行**；JWT 过期之后，公开公告程序仍然可以独立运行，但不能保证提醒所有相关活动。
